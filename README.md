# ☕ Starbucks Beverage Analytics Dashboard
### Brewing Insights. Fueling Connections.

## 📊 Project Overview

The **Starbucks Beverage Analytics Dashboard** is an interactive data visualization project developed using Microsoft Power BI. This project focuses on analyzing Starbucks beverages based on their nutritional values, beverage categories, caffeine content, sugar levels, and calorie distribution.

The dashboard presents meaningful insights through interactive charts, KPI cards, maps, and visual representations, making beverage data easier to understand and explore.

## 🎯 Project Objectives

- Analyze Starbucks beverages across different categories.
- Understand average sugar and calorie content.
- Evaluate caffeine levels across beverage categories.
- Identify the top 5 highest-caffeine beverages.
- Explore beverage category distribution.
- Analyze Starbucks' global presence through map visualization.
- Present nutritional information through an interactive dashboard.

## 🛠️ Tools & Technologies Used

- **Microsoft Power BI:** Interactive dashboard development.
- **Power Query:** Data cleaning and transformation.
- **DAX:** Creating calculated measures and KPIs.
- **Data Visualization:** Charts, maps, KPI cards, and slicers.
- **Microsoft Excel:** Dataset preparation and management.

## 📌 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

- **Total Beverages:** 33
- **Average Sugar:** 32.90

## 📈 Dashboard Features

### 1. Average Calories by Beverage Category
Analyzes the average calorie content across different Starbucks beverage categories.

### 2. Starbucks Global Presence
Uses map visualization to present geographical information related to Starbucks.

### 3. Beverage Category Distribution
Displays the distribution of beverages across different categories using a donut chart.

### 4. Average Caffeine by Category
Provides a visual comparison of caffeine-related information across beverage categories.

### 5. Top 5 Highest Caffeine Beverages
Highlights the five beverages with the highest caffeine content using product images.

### 6. Interactive Filters & Slicers
- Protein Range
- Beverage Preparation

These slicers help users explore and filter beverage information interactively.
